# Railway Seat Allocation Simulator v2 (Java Swing + JDBC)

## Run (Mac / Linux)
    cd RailwaySeatSimulator_v2
    javac *.java
    java -cp ".:sqlite-jdbc.jar" Main

## Run (Windows)
    javac *.java
    java -cp ".;sqlite-jdbc.jar" Main

sqlite-jdbc.jar is already included. The database file railway_v2.db is created on first run.
Saved tickets go into the "tickets" folder.
